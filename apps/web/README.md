# @omed/web

Web dashboard for Omed built with React 19, React Router v8 (SPA mode), Ant Design, and Tailwind CSS.

For monorepo architecture, environment setup, and design guidelines, refer to the root documentation:
- Architecture & Getting Started: [README.md](../../README.md)
- Agent Conventions & Module Architecture: [AGENTS.md](../../AGENTS.md)
- Visual Guidelines & Design Tokens: [BRANDING.md](../../BRANDING.md)

## Development

Run development server (port 3000):

```bash
bun run dev
```

Build and preview:

```bash
bun run build
bun run start
```

Typecheck:

```bash
bun run typecheck
```
